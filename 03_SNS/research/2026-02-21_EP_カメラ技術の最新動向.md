## 用語辞書（初心者向け）

| 用語 | 説明 | 身近な例 |
| :-- | :-- | :-- |
| CMOSイメージセンサー | 光を電気信号に変換する半導体チップ。各画素にフォトダイオードとアンプを搭載 | カメラの「目の網膜」にあたる部品 |
| 裏面照射型（BSI） | シリコン基板の裏側から光を取り込む構造。配線が邪魔しないので感度約2倍 | 窓ガラスの汚れ（配線）を裏から拭いて光を通す感じ |
| 積層型センサー | フォトダイオード層と回路層を別チップにして上下に積む構造 | 2階建ての家：1階で光を受け、2階で頭脳（処理）を動かす |
| コンピュテーショナルフォトグラフィ | ソフトウェア・AIでの画像処理を前提とした撮影技術 | 「撮ってから作る」写真。複数枚合成やAI補正で物理限界を超える |
| 回折限界 | 光が小さなレンズを通るときに曲がって像がボケる物理現象 | 小さな穴から覗くと景色がぼやけるのと同じ原理 |
| グローバルシャッター | 全画素を同時に露光する方式。動体歪みゼロ | 「パシャッ」と全員同時に写真を撮る（ローリングは上から順に走査） |
| SWIR（短波赤外線） | 人間の目に見えない赤外線帯域（0.9〜1.7μm）を撮影する技術 | 霧や煙の向こう側を「透視」できるカメラ |

## 仕組みの流れ（Concept Map）

```
[光] → [レンズ] → [カラーフィルター] → [マイクロレンズ]
                                              │
                                    ┌─────────▼──────────┐
                                    │ フォトダイオード層  │ ← 光→電荷変換
                                    │  （画素チップ）     │
                                    └─────────┬──────────┘
                                              │ 電荷信号
                                    ┌─────────▼──────────┐
                                    │ 信号処理回路層      │ ← ノイズ除去・増幅・AD変換
                                    │ （ロジックチップ）  │
                                    └─────────┬──────────┘
                                              │ デジタル信号
                                    ┌─────────▼──────────┐
                                    │ ISP / AIエンジン   │ ← HDR合成・超解像・ノイズ低減
                                    │ （コンピュテーショナル）│
                                    └─────────┬──────────┘
                                              │
                                    ┌─────────▼──────────┐
                                    │    最終画像         │
                                    └────────────────────┘
```

**説明**: 現代のカメラは「光学（レンズ）→ 電気変換（センサー）→ 計算処理（AI）」の3層構造。積層型センサーは真ん中の2層を物理的に分離して最適化し、最後の計算処理層がさらに画質を「創造」する。

**図解タイプ候補**: structure（3層アーキテクチャ）

## 限界・例外（Limits）

- **回折限界は物理法則であり、ソフトウェアでは根本的に超えられない**。コンピュテーショナルフォトグラフィは「補完」であって「置換」ではない（Fact）
- **積層型センサーのコスト問題**: 2チップを積層するため製造が複雑でコストが高い。ハイエンド端末以外への普及は遅い（Fact）
- **AI画像処理の「捏造」リスク**: AIが実際に存在しないディテールを生成する可能性があり、報道・医療分野では問題になりうる（Hypothesis）
- **グローバルシャッターのトレードオフ**: 現時点では解像度やダイナミックレンジがローリングシャッターに劣る（Fact）
