## 用語辞書（初心者向け）

| 用語 | 説明 | 身近な例 |
|:--|:--|:--|
| 蒸気圧縮サイクル | 冷媒を液体↔気体に変化させて熱を運ぶ冷却方式。150年以上使われている | 注射前にアルコールで腕を拭くとヒヤッとする。あれが気化熱 |
| HFC冷媒 | オゾン層は破壊しないが、CO2の1300〜4000倍の温室効果を持つ冷媒 | 「オゾンを守ったら温暖化を加速した」というジレンマの元凶 |
| キガリ改正 | 2016年採択。HFCの生産・消費を段階的に削減する国際条約 | 世界全体でHFCを2036年までに85%削減するルール |
| 磁気熱量効果 | 磁石に近づけると温まり、離すと冷える特殊な金属の性質 | 磁石で「冷やす」SF的冷蔵庫。ガドリニウム等の希土類金属を使用 |
| 弾性熱量効果 | 形状記憶合金を伸ばすと発熱し、縮めると冷える現象 | 輪ゴムを急に伸ばすと温かい→離すと冷たい。あの原理の超高性能版 |
| COP（成績係数） | 投入エネルギーに対する冷却/暖房出力の比率。高いほど省エネ | COP=3なら「1の電気で3の冷却」を生み出す。ヒートポンプの効率指標 |
| インバーター制御 | コンプレッサーの回転数を可変制御する技術。必要最小限の電力で運転 | 車のアクセルワーク。全開か停止ではなく、必要な分だけ踏む |

## 仕組みの流れ（Concept Map）

```
【従来技術：蒸気圧縮サイクル】

    ┌─── 圧縮（コンプレッサー）───┐
    │   低圧ガス → 高温高圧ガス     │
    │                                │
    ▲                                ▼
    │                          凝縮器（放熱）
 蒸発器（吸熱）              高温ガス → 常温液体
 低温液体 → 低圧ガス              │
 ← 庫内の熱を奪う                  │
    │                                │
    └──── 膨張弁 ◄──────────────────┘
           常温液体 → 低温液体


【次世代技術：弾性熱量効果】

    ┌─── 引っ張る ────┐
    │  合金が発熱      │
    │  熱を外部に放出  │
    │                  │
    │    NiTi合金      │
    │（形状記憶合金）  │
    │                  │
    └─── 緩める ──────┘
       合金が冷却
       周囲から熱を吸収
       → 庫内が冷える

    ✅ 冷媒ゼロ  ✅ 温室効果ゼロ  ✅ 静音
```

## 限界・例外（Limits）

- **弾性熱量効果はまだ研究段階**: HKUSTのデバイスは20mlの水を凍らせる規模。家庭用冷蔵庫サイズへのスケールアップは未実現（Fact）
- **磁気冷却のコスト問題**: ガドリニウム等の希土類金属が必要で、現時点では蒸気圧縮より高コスト（Fact）
- **AI冷蔵庫のプライバシー懸念**: 庫内カメラやスマホ連携は食生活データの収集を意味し、プライバシーの議論が必要（Hypothesis）
- **自然冷媒の可燃性リスク**: プロパンやイソブタンなどの炭化水素系自然冷媒は可燃性があり、安全設計が必須（Fact）
