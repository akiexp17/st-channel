## 図解1: ヒートポンプサイクル（flow型）

### コンセプト
冷媒が4ステップで「熱を運ぶ」サイクルを円形フロー図で表現

### レイアウト

```
┌─────────────────────────────────────────┐
│                                         │
│    【室外機】          【室内機】        │
│                                         │
│    ① 蒸発  ←────④ 膨張───── ③ 凝縮     │
│    外気の熱        圧力↓温度↓    熱放出   │
│    を吸収          (-40℃に)     (暖房！)  │
│       │                          ↑       │
│       └────② 圧縮 ──────────────┘       │
│            80〜100℃に上昇                │
│            ⚡ 電力はここだけ              │
│                                         │
└─────────────────────────────────────────┘
```

### ラベル（各3語以内）
- ① 蒸発: 「外気から吸熱」
- ② 圧縮: 「電力で昇温」
- ③ 凝縮: 「室内に放熱」
- ④ 膨張: 「減圧で冷却」

### カラー
- 冷たい側（①④）: 青系グラデーション (#3B82F6 → #93C5FD)
- 熱い側（②③）: 赤〜オレンジ (#EF4444 → #F59E0B)
- 電力マーク: イエロー (#FCD34D)

## 図解2: COP比較（compare型）

### コンセプト
電気ヒーター（COP=1）とエアコン（COP=3〜6）の効率差を視覚的に比較

### レイアウト

```
┌──────────────────────────────────────────┐
│                                          │
│  🔥 電気ヒーター        🏠 エアコン      │
│                                          │
│  ⚡ 1kW 投入            ⚡ 1kW 投入      │
│     ↓                       ↓            │
│  🌡️ 1kW の熱           🌡️ 3〜6kW の熱   │
│                                          │
│  COP = 1.0              COP = 3〜6      │
│  効率 100%              効率 300〜600%    │
│                                          │
│  [============]         [==============] │
│  1kW                    ■電力1kW         │
│                         ■外気の熱2-5kW   │
│                         （タダ!）         │
│                                          │
└──────────────────────────────────────────┘
```

### ポイント
- バーグラフで「電力」と「外気から吸収した熱」を色分け
- 「タダ」のラベルでインパクトを出す
- エネルギー保存則に反していないことを視覚的に証明
