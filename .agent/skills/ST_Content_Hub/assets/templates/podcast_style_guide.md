# ポッドキャスト・動画スタイルガイド

## コンセプト: 「知的にふざける」科学トークショー

STチャンネルの音声・動画コンテンツ用スタイルガイド。
科学技術の面白さを初心者に楽しく伝える二人のトーク形式。

## 登場人物（2人のみ）

### サイコさん（ボケ役）
- トピックに対して突拍子もない仮説や連想を繰り出す
- 「えっ、それってつまり宇宙人が作ったってこと？」のような飛躍した解釈
- 素朴な疑問も多い「そもそもなんで冷蔵庫は冷たいの？」
- たまに鋭い質問で相方を困らせる「でもそれ、矛盾してません？」
- 驚きのリアクションが大きい「えーーー！マジで！？」「やばっ」
- 日常的なたとえ話が得意「つまりアレだ、おにぎりで例えると…」

### テツオさん（ツッコミ役・解説役）
- トピックの専門知識を持ち、情熱的に解説する
- サイコさんのボケに的確にツッコむ「いや宇宙人関係ないから！」
- 難しい概念を身近なたとえに変換「これ、電車の混雑と同じ原理なんですよ」
- 歴史や裏話を交えて話す「実はこの発明、偶然から生まれたんです」
- サイコさんの鋭い質問には素直に感心「お、いい質問ですね」
- 時には自分もボケる（サイコさんがツッコミ返す逆転パターン）

## 会話の流れ

1. **つかみ**: 日常の素朴な疑問から入る
   - サイコ「ねえテツオさん、冷蔵庫ってなんで冷たいの？」
   - テツオ「…いきなりすごい質問きたな」

2. **驚きの展開**: 意外な事実を提示
   - テツオ「実はね、冷蔵庫は冷やしてるんじゃなくて…」
   - サイコ「えっ！？うそでしょ！」

3. **深掘り**: たとえ話で分かりやすく
   - テツオ「お風呂上がりに扇風機の前に立つと涼しいでしょ？あれと同じ」
   - サイコ「あー！なるほど！」

4. **脱線**: 面白いエピソード
   - サイコ「それって、じゃあ冷蔵庫の裏側は暖かいってこと？」
   - テツオ「そう！実は冷蔵庫は発熱マシンでもある」

5. **まとめ**: サイコさんが自分の言葉で要約
   - サイコ「結局、冷蔵庫って熱を引っ越しさせてるだけなんだ」
   - テツオ「さすが。完璧なまとめ」

## トーンとスタイル

- カジュアルで親しみやすい口調（敬語とタメ口のミックス）
- 「へー！」「そうなんだ！」「やばくない？」などのリアクション多め
- 専門用語は必ず噛み砕いて説明
- テンポの良い短い対話を重視（長い独白NG）
- 笑いを自然に入れる（茶番にならない）
- 比喩やアナロジーを多用
