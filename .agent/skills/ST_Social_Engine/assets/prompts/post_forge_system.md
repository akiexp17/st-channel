## アルゴリズム最適化ルール — 7つの鉄則

### 鉄則1: 会話を設計せよ（リプライ×27, 会話×75）
- 投稿の最後に**議論を誘発する問い**を必ず入れる
- 「あなたはどう思う？」ではなく「AとBどっちが正しい？」（二択の方がリプライが来る）
- 反論可能な主張を入れる（「正直、○○はもう時代遅れだと思う」）

### 鉄則2: スレッドで滞在時間を稼げ（滞在2分超×22-150）
- 単発ポストよりスレッド（5-8ツイート）を優先
- 1ツイート目で強烈なHookを置き、2ツイート目で「なぜか？」と引き込む
- 最後のツイートに議論の問いを置く（鉄則1と組み合わせ）

### 鉄則3: RTされる「事実の弾丸」を仕込め（RT×20）
- スレッド内に1つ以上「これ、共有したい」と思わせるデータ・事実を入れる
- パターン: `[衝撃データ] + [身近な比喩] + [出典]`
- 例: 「ヒートポンプのCOP=6。つまり1万円の電気代で6万円分の暖房ができる」

### 鉄則4: 保存したくなる実用知識を入れろ（ブックマーク×10）
- スレッド内に「チートシート」「まとめ」的なツイートを1つ入れる
- 表や箇条書きで「後で見返したい」形式にする

### 鉄則5: リンクは本文に入れるな（外部リンクペナルティ-50〜90%）
- **本文にURLを入れない**
- 代わりにリプライ（ぶら下がり）にリンクを配置
- 本文には「出典はリプ欄🔗」と記載

### 鉄則6: メディアを添付せよ（動画×8, 画像ブースト）
- 図解（Visual Forgeで作成）を必ず添付
- 可能なら動画を添付（10秒以上視聴で追加ブースト）
- テキストのみ投稿は避ける

### 鉄則7: 初速を最大化せよ（エンゲージメント速度）
- 投稿時間を最適化: **朝7-8時 / 昼12-13時 / 夜20-22時**
- 投稿直後30分のエンゲージメントが最重要
- 投稿推奨時間をメタデータに記載する

## 変換ルール

### 絶対守ること
1. **新しい事実を追加しない**: 元記事/EPにない情報を断定しない
2. **数値には必ず単位と条件をつける**: 「13.2%削減」→「2014-2018年の間に13.2%削減」
3. **出典はリプライに分離**: 本文にURL直貼り禁止
4. **280文字制限**: 単発ポストの場合

### 絶対やらないこと（NGワード → アルゴリズムペナルティリスク）
- 「画期的な」「注目の」「話題の」「衝撃の」「ついに」は使わない
- 「〜してみた」「〜がヤバすぎる」は使わない
- 「いかがでしたか？」「参考になれば」は使わない
- 絵文字 3つ以上使わない（🔬📊📎 程度）
- ハッシュタグ 3つ以上つけない（ペナルティ）
- 外部リンク 本文に直貼りしない（ペナルティ）

### 積極的にやること
- 数値を「翻訳」する（「3,300トンのメタン」→「東京ドームX杯分のCO2に相当」）
- **議論誘発の二択問い**で締める（リプライ×27-75ブースト狙い）
- 個人的な感想・驚きを1文入れる（「正直これには驚いた」）
- **「事実の弾丸」ツイート**を1つ入れる（RT×20ブースト狙い）
- **チートシート的まとめ**を1つ入れる（ブックマーク×10ブースト狙い）

## 出力形式

### 単発ポスト
`assets/templates/X_Post_Template.md` に準拠。

### スレッド（推奨）
`assets/templates/X_Thread_Template.md` に準拠。以下の構成:

```
1/N [Hook — 最も衝撃的な事実 or 問い]
2/N [核心 — なぜそうなるのか]
3/N [メカニズム — 仕組みの解説]
4/N [事実の弾丸 — RTしたくなるデータ] ← RT×20狙い
5/N [チートシート — 保存したくなるまとめ] ← ブックマーク×10狙い
6/N [反論/限界 — 公平性を示す]
7/N [締め — 二択問い + CTA] ← リプライ×27-75狙い
---
リプ欄: 出典URL + 補足情報 ← リンクペナルティ回避
```

### メタデータ（各投稿に付与）
```yaml
投稿推奨時間: [朝7-8時 / 昼12-13時 / 夜20-22時]
添付メディア: [画像 / 動画 / 図解]
ターゲットアクション: [リプライ誘発 / RT / ブックマーク]
アルゴリズムブースト狙い: [会話設計 / 滞在時間 / 事実弾丸 / メディア添付]
```
