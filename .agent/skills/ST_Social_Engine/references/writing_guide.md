## 1. 断定強度チャート

| レベル | OK表現 | NG表現 | 使用条件 |
| :-- | :-- | :-- | :-- |
| **Fact** | 「〜である」「〜と確認された」 | — | EP出典あり + 交差検証済み |
| **Model** | 「〜と考えられている」「例えると〜」 | 「〜である」 | 比喩・モデル。必ず「あくまで例えだが」を添える |
| **Hypothesis** | 「〜かもしれない」「筆者の見立てでは」 | 「〜は確実」 | 推測・予想。根拠を併記 |

> ルール: FactをModelの表現で弱めない。正確なものは正確に書く。

## 2. 二層構造の書き方

技術的な説明は必ず**直感→理屈**の2段階で書く。

**例1（物理）**:
```
【直感】空が青いのは、太陽光が大気中の小さな粒子にぶつかって
        散らばるとき、青い光だけがよく散らばるからです。
【理屈】レイリー散乱の強度は波長の4乗に反比例します。
        可視光の中で波長が最も短い青色光(~450nm)は、
        赤色光(~700nm)に比べて約5.5倍強く散乱されます。
```

**例2（AI）**:
```
【直感】包丁の刃先を野菜の形に合わせて自動変形させる技術です。
【理屈】Cross-Attention機構で形状データをネットワークの
        トランク部分に直接注入し、物理場の予測精度を向上させています。
```

**ポイント**:
- 直感レイヤーだけ読んでも大意は掴める
- 理屈レイヤーまで読めば正確に理解できる
- 「【直感】」「【理屈】」のラベルは実際の記事では使わなくてよい。自然に接続する

## 3. 脱AI文体 — 10のチェックポイント

| # | ポイント | NG例 | OK例 |
| :-- | :-- | :-- | :-- |
| 1 | 教科書感の排除 | 「〜について説明します」 | 「不思議に思ったこと、ありませんか？」 |
| 2 | リズムの変化 | 「〜です。〜です。〜です。」 | 「〜だ。〜である。…なのだ、これが。」 |
| 3 | 感情の注入 | 「興味深い結果です」 | 「正直、この数字を見たとき鳥肌が立った」 |
| 4 | 会話的な調子 | 「次に述べる」 | 「ここがミソなんですが」 |
| 5 | 共感の獲得 | 「多くの人は知りません」 | 「あなたもそう思ってませんでした？」 |

## 4. 数値の翻訳ルール

生のデータは読者に刺さらない。必ず「翻訳」する。

| 生データ | → | 翻訳後 |
| :-- | :-- | :-- |
| 3,300トンのメタン | → | 東京ドームX杯分のCO2に相当 |
| 処理速度1.2TFLOPS | → | 1秒間に1.2兆回の計算 |
| 0.3mmの精度 | → | 髪の毛の太さの3倍 |

**ルール**:
- 元の数値+単位+条件は必ず残す
- 翻訳は「補足」として添える
- 条件（いつ、どこで、誰が測定）を省略しない
