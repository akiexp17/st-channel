## 1. アルゴリズムのパイプライン

```
候補ソーシング → ランキング（Heavy Ranker）→ フィルタリング → For You表示
```

### 候補ソーシング

## 2. エンゲージメント重み付け（いいね = 1x 基準）

### ポジティブシグナル

| ランク | アクション | 重み | ポスト戦略 |
| :--: | :-- | :--: | :-- |
| 🥇 | リプライ→返信（会話連鎖） | **×75-150** | 議論を誘発する問いを投稿に入れ、来たリプに返信する |
| 🥈 | リプライ | **×27** | 二択質問・反可能な主張で誘発 |
| 🥉 | 滞在2分超 | **×22** | スレッドで情報量を詰め、読み込ませる |
| 4 | RT / リポスト | **×20** | 「これ共有したい」と思わせるデータ・事実 |
| 5 | プロフィールクリック | **×12** | 「この人誰？」と思わせる専門性・独自視点 |
| 6 | ブックマーク | **×10** | チートシート・まとめ表で保存欲を刺激 |
| 7 | 動画10秒視聴 | **×8** | 図解動画（Visual Forge）を添付 |
| 8 | 引用RT | **×5** | 引用しやすい端的な主張を含める |
| 9 | いいね | **×1** | ベースライン。これだけでは拡散しない |

### ネガティブシグナル

| アクション | 重み | 回避策 |
| :-- | :--: | :-- |
| ツイート報告 | **-369x** | 正確な情報 + 出典必須。煽り厳禁 |
| ブロック | **-74x** | スパム行為をしない |
| ミュート | **-74x** | 投稿頻度を適正に（1日1-2投稿） |
| 「表示減らす」 | **-74x** | ユーザーに不快感を与えない |

## 3. コンテンツ別ブースト / ペナルティ

### ブースト

| 要素 | 効果 | 活用法 |
| :-- | :--: | :-- |
| X Premium認証 | In-Net ×4, Out-Net ×2 | 認証アカウントで投稿 |
| 動画添付 | 大幅ブースト | 10秒以上視聴でボーナス |
| 画像添付 | 中程度ブースト | 図解を毎回添付 |
| セルフリプライ（スレッド） | ブースト | 5-8ツイートのスレッド推奨 |
| トレンドトピック | 可視性向上 | トレンドタグを1つ使用 |

### ペナルティ

| 要素 | ペナルティ | 回避策 |
| :-- | :--: | :-- |
| **外部リンク** | **-50〜90%** | リプ欄に分離。本文「出典はリプ欄🔗」 |
| 複数ハッシュタグ (3+) | ペナルティ | 0-2個に制限 |
| フォロー>>>フォロワー比率 | ペナルティ | フォロワー獲得を優先 |
| ALL CAPS / 大文字のみ | ペナルティ | 通常の表記を使用 |

## 4. 投稿タイミング最適化

### エンゲージメント速度（Velocity）
投稿後 **30分以内** のエンゲージメントが最重要。
初速が高い投稿はアルゴリズムが「高品質」と判定し、さらに拡散する。

### 推奨スロット（日本時間）

| 時間帯 | ターゲット | 期待効果 |
| :-- | :-- | :-- |
| 朝 7:00-8:00 | 通勤層 | 安定した初動 |
| 昼 12:00-13:00 | ランチタイム | 高シェア率 |
| 夜 20:00-22:00 | ゴールデンタイム | **最高エンゲージメント** |

## 5. ST Channel向け最適投稿パターン

### Sパターン: スレッド（推奨）

```
1/7 🔬 [Hook — 数値衝撃 or 逆説断言]
     "えっ、マジで？"を狙う一文

2/7    [核心 — なぜそうなるのか]
     Hookの答え。メカニズムの入口

3/7    [メカニズム — 仕組み図解]
     📊 図解画像を添付（Visual Forge）

4/7 🚀 [事実の弾丸 — RTしたくなるデータ]
     身近な比喩で翻訳した数値 ← RT×20

5/7 📋 [チートシート — 保存用まとめ]
     表 or 箇条書きで整理 ← ブックマーク×10

6/7    [反論/限界 — 公平性]
     「ただし○○は注意」で信頼を獲得

7/7 💬 [締め — 二択問い]
     "AとBどっち？" ← リプライ×27-75
     
---
リプ欄: 🔗 出典URL + 補足（リンクペナルティ回避）
```

### Qパターン: 単発ポスト（280文字以内）

```
[Hook — 1文目で手を止める]
[核心データ — 1つだけ]
[個人的感想 — 1文]
[二択問い or CTA]

📊 図解画像添付
🔗 出典はリプ欄
```
